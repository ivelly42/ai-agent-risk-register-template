## What This Risk Register Covers

| Risk Register Area | What The Buyer Needs |
| --- | --- |
| Risk Inventory | List prompt, tool, data, access, security, cost, delivery, and revenue-proof risks |
| Severity | Score likelihood, impact, exposure, owner, mitigation, and review date |
| Access and Data | Track secrets, production permissions, customer data, and public-sharing boundaries |
| Verification | Attach commands, screenshots, URLs, digests, reviewer notes, and acceptance gates |
| Cost Control | Track model spend, retry loops, cleanup avoided, and team-license payback risk |
| Incident Response | Pre-assign rollback, postmortem, customer update, and corrective-action owners |
| Handoff | Preserve changed files, blockers, follow-up, risk owner, and unresolved gaps |
| Revenue Proof | Prevent order intent, views, stars, forks, or downloads from being counted as revenue |
